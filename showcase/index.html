Under the hood

How it is wired

A system-prompt agent, not a script. It binds to whatever tools the live MCP exposes, so it survives API changes. No keys in the repo. Account access is brokered through the authenticated agentic sub-account.

Controls

One-line commands

Natural language works too. Sentinel maps intent to the closest command and confirms briefly.

scan market

Rank the watchlist by opportunity score.

analyze <SYM>

Full multi-timeframe read + score breakdown.

risk dashboard

Equity, exposure, daily budget, live gates.

portfolio

Balances, open positions, unrealized PnL.

propose <SYM>

Run the workflow and emit a sized proposal.

confirm paper

Log the last proposal as a paper trade.

disable safety mode

Human-only. Live trades still need confirm.

set risk <profile>

Conservative / Balanced / Aggressive.

Get it running

Connected in about two minutes

STEP 01

Connect the MCP

Point your agent at the official Agent OS endpoint and authorize the sub-account.

# Claude Code claude mcp add \ --transport http \ binance-agentos \ https://agent.binance.com/mcp/agentic
STEP 02

Load the brain

Paste the contents of AGENT.md into your system prompt. That single file is the whole agent, 231 lines of operating procedure.

STEP 03

Go

Open a chat and type scan market. Safety Mode is on. It reads everything, trades nothing, until you decide otherwise.

On the figures above. The SOL proposal, scores, and gate readings are a worked reference sample so you can see the output shape. At runtime every value streams live from the Binance Agent OS MCP against your own agentic sub-account. Nothing here is pre-baked into the agent.
